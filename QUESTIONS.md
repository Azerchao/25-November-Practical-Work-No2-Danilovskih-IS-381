# Ответы на контрольные вопросы

1. **fn vs function.** `fn` — короткая запись: тело состоит из одного выражения, `return` не нужен, внешние переменные захватываются автоматически по значению. `function` допускает много инструкций, требует `return` и явного `use` для внешних переменных (в т.ч. по ссылке `use (&$x)`).

2. **Захват переменных.** `fn` автоматически копирует нужные внешние переменные по значению в момент создания функции. Внутри хранится копия, поэтому последующее изменение внешней переменной на функцию не влияет.

3. **Несколько инструкций.** Нельзя — только одно выражение. Для сложной логики используют обычную `function () use (...) { ... }` или именованную функцию, которую вызывают из `fn`: `fn($x) => process($x)`.

4. **Возвращаемые значения.** `array_map` — новый массив результатов callback(элемент). `array_filter` — массив элементов (с сохранением ключей), для которых callback вернул true; callback возвращает bool. `array_reduce` — одно итоговое значение; callback получает ($накопитель, $элемент) и возвращает новый накопитель.

5. **Оператор `<=>`.** Возвращает -1, 0 или 1, если левый операнд меньше, равен или больше правого. Именно такой результат ожидает `usort`, поэтому `fn($a,$b) => $a['age'] <=> $b['age']` — компактное сравнение. Для убывания операнды меняют местами.

6. **`$f = fn($x) => fn($y) => $x * $y; echo $f(2)(5);`** Выведет `10`. `$f(2)` возвращает функцию, в которую захвачено `$x = 2`; вызов её с `5` даёт `2 * 5`.
